================================================================
 قواعد الحماية الخاصة بـ Firebase Storage (Firebase Storage Rules)
================================================================

لضمان عمل رفع ملفات الـ APK والأيقونات ولقطات الشاشة بدون خطأ صلاحيات،
يرجى نسخ القواعد التالية ولصقها في لوحة Firebase Console:

1. افتح مشروعك في Firebase Console (https://console.firebase.google.com)
2. اذهب إلى قسم Build -> Storage
3. اختر تبويب القواعد (Rules)
4. استبدل القواعد القديمة بالقواعد التالية:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      // السماح بالقراءة للجميع دون قيود (لتنزيل التطبيقات وعرض الصور في المتجر)
      allow read: if true;
      
      // السماح بالكتابة/الرفع للمستخدمين المسجلين فقط
      allow write: if request.auth != null;
    }
  }
}

5. اضغط على زر "نشر" (Publish).

================================================================
 خطوة إضافة بصمات SHA-1 و SHA-256 للمطور (Google Sign-In)
================================================================

حل مشكلة (10 DEVELOPER_ERROR) الخاصة بتسجيل الدخول بـ Google:

1. في جهازك، قم بتشغيل الأمر التالي في التيرمنال لجلب بصمة SHA-1 للـ Debug:
   ./gradlew signingReport

2. انسخ قيم SHA-1 و SHA-256 الظاهرة.

3. افتح Firebase Console -> Project Settings -> Your Apps -> Android App.

4. اضغط على "Add fingerprint" وقم بإضافة بصمة SHA-1 وبصمة SHA-256.

5. قم بتنزيل ملف google-services.json المحدث واستبدله في المجلد app/ بالمشروع.
